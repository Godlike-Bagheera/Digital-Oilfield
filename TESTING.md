# Тестирование системы

## Быстрая проверка всех компонентов

Запустите из корня проекта:
```bash
python test_all.py
```

## Тестирование бэкенда отдельно

```bash
cd backend
python test_system.py
```

## Тестирование фронтенда отдельно

```bash
cd frontend
node test_frontend.js
```

## Что проверяется

### Бэкенд:
- Модели базы данных и их структура
- Расчёт индекса здоровья скважин
- Генерация алертов при аномалиях
- Доступность REST API эндпоинтов
- Работа симулятора телеметрии

### Фронтенд:
- Наличие всех зависимостей
- Успешная сборка проекта
- Отсутствие критических ошибок

## Устранение неполадок

### Ошибка подключения к базе данных
Убедитесь, что выполнены миграции:
```bash
cd backend
python manage.py migrate
```

### Ошибка импорта модулей
Убедитесь, что установлены все зависимости:
```bash
cd backend
pip install -r requirements.txt

cd ../frontend
npm install
```

### API недоступен
Убедитесь, что Django сервер запущен:
```bash
cd backend
python manage.py runserver
```
